# Przykład użycia Prometheus

Ten katalog zawiera przykłady użycia Prometheus, opisane w dostarczonym tekście.

## Podsumowanie

Prometheus to otwarte narzędzie do monitorowania i alertowania. Przechowuje metryki jako dane szeregów czasowych z etykietami klucz-wartość. Główne cechy to wielowymiarowy model danych, język zapytań PromQL oraz model zbierania metryk typu pull przez HTTP. Dla zadań krótkotrwałych można użyć Push Gateway. Prometheus jest idealny do niezawodnego monitorowania numerycznych szeregów czasowych, zwłaszcza w dynamicznych architekturach zorientowanych na usługi, ale nie nadaje się do zastosowań wymagających 100% dokładności, jak systemy bilingowe.

Szczegółowy opis oraz przykłady kodu znajdują się w osobnych plikach w tym katalogu.
